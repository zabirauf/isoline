Entry point: runs one harness attempt inside full diagnostics, then classifies and normalizes the result.

  1. Create lifecycle diagnostics (opens the harness span).
  2. Phase prepare: assert context-engine support, then start the child run span.
  3. Phase send: run execute(params) in the run trace.
  4. On a throw: fail() emits the error events, then rethrow. Always unsubscribe.
iCompletion events fire after the finally block, so a throwing emitter cannot double-report.
